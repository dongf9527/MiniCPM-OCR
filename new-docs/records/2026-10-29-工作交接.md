## 5. 已知坑(防再踩)

- **conda HOST 劫持**:激活 minicpmocr 环境后 `$HOST` 是编译三元组而非主机名;任何读 `$HOST` 决定绑定地址的脚本都会踩。23 号已钉定,新写脚本一律显式指定绑定地址(用 IP 字面量)。
- **企业网 DNS 对未知域名回答不稳定**:同一坏域名可能时而返回非本机 IP(198.10.0.7)、时而 NXDOMAIN(`Errno -2`)、时而 0.0.0.0;绑定地址必须用 `127.0.0.1` 而非任何主机名,排查用 `ss -tlnp` 看实际绑定。
- **沙箱会重置**:重置后凭据丢失、本地未推送的工作全灭;按规则文档 §3 三步恢复凭据,工作内容靠 git 历史承接——这是"唯一同步方式"规则存在的根本原因,故改动请小步勤推。
- **两条预期告警**:12 号的 `qwen3_5 ... does not recognize` 与 `Unknown RoPE type: default` 属预期;50 号里 Jev `[–]` 在最小路径(`SKIP_JEV=true`)下属预期,启动 Jev 后重跑会变 `[✓]`。
- **生成物不入库**:`llama.cpp/`、`gguf/`、`venv-*/`、`run/` 已 gitignore;沙箱重建后需重跑脚本生成,实机生成物不受影响。
